### Step-by-Step Screenshot Generation Workflow

#### 1. EDA & Model Plots (Already Generated)
Files `01_eda_class_balance.png` and `02_eda_correlation.png` are automatically synced from `reports/figures/`.

#### 2. MLflow Tracking UI
```bash
# In your terminal with .venv active:
mlflow ui --backend-store-uri ./mlruns --port 5000
# Open http://127.0.0.1:5000 in your browser
# Capture 03_mlflow_runs.png (the runs table)
# Click on the logistic_regression run
# Capture 04_mlflow_run_detail.png (parameters, metrics, and artifact tree)
```

#### 3. Pytest Unit Tests
```bash
pytest -v
# Capture 05_pytest_pass.png showing all 21 tests green
```

#### 4. GitHub Actions (CI/CD)
```bash
# Initialize git and push to your GitHub repo:
git init
git add .
git commit -m "Initial end-to-end MLOps pipeline"
git remote add origin https://github.com/Mohana1507/heart-disease-mlops.git
git branch -M main
git push -u origin main
# Open your GitHub repository -> Actions tab
# Capture 06_actions_run.png (workflow with all 4 jobs green)
# Capture 07_actions_artifacts.png (artifacts section at bottom of page)
```

#### 5. Docker Containerization
```bash
docker build -t heart-disease-api:1.0.0 .
# Capture 09_docker_build.png
docker run -d --name heart-api -p 8000:8000 heart-disease-api:1.0.0
python scripts/predict_sample.py --url http://localhost:8000
# Capture 10_docker_predict.png
```

#### 6. Kubernetes Cluster
```bash
# If using Docker Desktop, ensure Kubernetes is enabled in settings.
# If using Minikube:
minikube start
eval $(minikube docker-env)  # PowerShell: & minikube -p minikube docker-env | Invoke-Expression
docker build -t heart-disease-api:1.0.0 .

kubectl apply -f k8s/deployment.yaml -f k8s/service.yaml
kubectl get pods,svc
# Capture 11_k8s_pods_svc.png

# For Minikube in separate terminal: minikube tunnel
# Test endpoint:
curl -X POST http://localhost/predict -H "Content-Type: application/json" -d @- <<EOF
{"age":63,"sex":1,"cp":1,"trestbps":145,"chol":233,"fbs":1,"restecg":2,"thalach":150,"exang":0,"oldpeak":2.3,"slope":3,"ca":0,"thal":6}
EOF
# Capture 12_k8s_predict.png

kubectl logs -l app=heart-disease-api --tail=25
# Capture 13_api_logs.png
```

#### 7. Monitoring (Prometheus & Grafana)
```bash
docker compose up --build -d
python scripts/load_test.py --requests 300
# Open http://localhost:3000 (login: admin / admin)
# Navigate to Dashboards -> Heart Disease API
# Capture 14_grafana_dashboard.png showing request throughput, latency, and prediction distribution
docker compose down
```
